# Supported integrations

| Provider | Environment | Current capability |
|---|---|---|
| Twelve Data | Data | Save, encrypt, test and use for authenticated chart candles |
| Polygon | Data | Save, encrypt and test |
| Alpaca | Paper | Save, encrypt and validate paper account |
| OANDA | Practice | Save, encrypt and validate practice account |
| Interactive Brokers | Paper | Save account reference; Gateway/OAuth required for full validation |

Live broker environments and real-money execution are intentionally rejected.
